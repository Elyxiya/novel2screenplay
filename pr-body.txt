## Summary

- **AgentLLMProvider**: Wraps `LLMProvider`, accumulates tool results, parses OpenAI function-calling responses (`tool_calls` format), exposes `addToolResults()` for the agent loop.
- **tool-registry**: Converts `AgentTool` definitions to OpenAI `tools[]` format with full JSON Schema support (enum, min/max, defaults, required).
- **message-converter**: Bidirectional conversion between `AgentMessage` (with `tool` role) and `LLMMessage` (OpenAI-compatible); parses `tool_calls` from LLM response.
- **PromptEngine**: Builds system prompts with tool descriptions, calling protocol, and JSON output instructions; extracts tool_calls from content when model does not use native function-calling.
