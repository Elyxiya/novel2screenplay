# 数据流总览

> 关联图：[数据流总览.svg](./数据流总览.svg)

Novel2Screenplay 的全局数据流骨架图，将四个子模块（内容转化、存储、Agent 编排、SSE 实时反馈）压缩到一张纵向链路中。本文档对其余三张细节图作为入口使用。

## 顶层链路

```
前端页面 → API 路由层 → 业务引擎 → 内容转化 / Agent 编排
                                ↓
                     LLM 推理抽象层
                                ↓
                     存储适配层 repository
                                ↓
                     @novel/db DbEngine
                          ↙        ↘
                    SQLite      PostgreSQL
```

## 各层职责

| 层级 | 内容 | 对应细节图 |
|---|---|---|
| 前端 → API | `/api/pipeline · drama · writer · agent · result`，SSE 实时订阅 | — |
| 业务引擎 | 转换流水线（Phase1→4）、分镜引擎、多 Agent 编排 | 内容转化链路 / Agent 编排与质量关卡 |
| LLM 抽象层 | DeepSeek / OpenAI / Custom 统一接入 | — |
| 存储适配层 | repository：job / novel / drama / history / agent-task / user …，用户隔离 | 双后端存储 |
| DbEngine | `prepare().run / get / all` 同步抽象，按 `DATABASE_URL` 探择 | 双后端存储 |

## 关键信号

- **SSE 实时推送**：`progress / phase / log / complete`，含心跳与重连。
- **用户隔离**：所有 repository 以 user 维度隔离，多租户安全边界。
- **双向箭头**：品牌色（紫）表示编排/落库主路径；灰色为辅助流转。
