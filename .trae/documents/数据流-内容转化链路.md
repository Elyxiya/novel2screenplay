# 内容转化链路（小说 → 剧本 → 分镜）

> 关联图：[数据流-内容转化链路.svg](./数据流-内容转化链路.svg)

核心业务转化的单向流水线，聚焦「输入素材如何一步步变成结构化的戏剧成果」。

## 主链

```
小说资产 → 转换流水线（LLM 四阶段） → 剧本 YAML → 短剧分镜
```

| 节点 | 说明 | 落库 |
|---|---|---|
| 小说资产 | 上传 / 创作台原始素材 | novel |
| 转换流水线 | 四阶段 LLM 处理 | job（进度快照） |
| 剧本 YAML | 结构化工整剧本，可编辑/导出/溯源 | screenplay |
| 短剧分镜 | 基于剧本一键生成，含景别·运镜 | drama |

## 流水线内部四阶段

1. **① 分析**：抽取角色 / 地点等要素，作为后续转换的上下文。
2. **② 场景切割**：按章按场切分，形成可独立处理的场景单元。
3. **③ 场景转换**：LLM 逐场转换为剧本场景。
4. **④ 合并校验**：去重、补全 sourceRefs，物化为最终剧本。

```
①分析 → ②场景切割 → ③场景转换 → ④合并校验
```

## 溯源链

- 各阶段成果以 `sceneRefs / sourceRefs` 回跳到源章节，保证逐场可追溯。
- 全程链路标识：`novelId → jobId → dramaId`，贯穿存储与前端呈现。

## 相关单据

- 转换进度、阶段状态经 job repository + SSE 实时推给前端。
- 最终剧本以 screenplay contract（zod-4）校验后落库。
