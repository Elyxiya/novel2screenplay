## 四、质量工程成果（本项目最有辨识度的部分）

### 4.1 评测基建

不是"跑一次看着还行"，而是把评测做成可复现的脚本与口径：

| 脚本/工具 | 回答什么问题 |
|---|---|
| `annotate` → `review-sheet` → `freeze` → `score` | 金标注全流程：预标 → 人工抽检 → 冻结 → 对 reviewed 金标注打分 |
| `baseline.mjs` | 每样本 3 次运行 → mean±σ；区分**跨运行一致性**与**准确率**，剔除自证运行 |
| `phase1-ab.mjs` | Phase1 三模式（truncate / mapreduce / longctx）A/B |
| `stability.mjs` / `drift.mjs` / `drift-check.mjs` | judge 复跑方差（Δ_tail）、输出稳定性、时序漂移阈值比对 |
| `prompt-diff.mjs` | 提示词版本对比（行尾归一，避免 hash 假差异） |
| `model-matrix.mjs` | 模型 × 样本矩阵，暴露"静默模型回退" |
| `conflict.mjs` | 剧本逻辑漏洞三规则检测 |
| `doc-check.mjs` | 文档一致性 12 类校验（路径 / 阈值 / 开关 / 互链 / 承诺规则 / 字段 / 状态 / 时效 / 术语 / 日志 / 参数表） |
| `snapshot.mjs` | 一键生成带时间戳的状态快照，杜绝手抄数字 |

### 4.2 关键结果（均带日期）

### 4.3 方法沉淀（比数字更可迁移）

- **预注册判据**：Phase1 翻默认先冻结规则 R1/R2/R3（`eval/flip-decision.ts` + 9 例单测），"缺数据不裁决"；最终翻默认被明确登记为**所有者决策覆盖预注册门槛**（附风险与回滚方式），而不是事后合理化。
- **口径先行**：把「在场 / 提及」「别名 / 描述」「墓碑」拆成不同字段与不同校验，一次性消掉 6 个孤儿角色，并纠正 13 处「妇女」被当成同一人的别名合并。
- **不对单次采样下结论**：跨运行一致性用 3 次 mean±σ；温度消融在第二个样本上未复现，就把结论降级而不是保留。
- **不静默回退**：五个评测脚本的缺失/回退路径一律 `console.warn`，避免同一指标出现两个数。
- **检查器也要被检验**：`doc-check` 先被变异测试咬过（CRLF 空解析、子串匹配误判），修完才敢用于门禁。
- **问题账本**：38 条「现象 → 根因 → 解法 → 证据」+ 12 条判断原则 + 「原则 ↔ 保护措施」审计表，失误（误删 18 个文件、管道改乱中文）也入账。

## 六、对外可讲的三条故事（简历 / 答辩）

1. **长文本上下文工程**：三模式（截断 / 按章 map-reduce / 整本长上下文）+ 全局设定卡 + 场景级实体注入 + 滚动摘要 + 未闭合伏笔 + 预算守卫；切换只有一个决策点，默认值有数据与回滚开关。
   *证据*：Phase1 F1 0.752 → 0.886；截断样本召回 10.7 → 34。
2. **任务可靠性**：状态落库、跨进程 CAS 恢复锁、只重跑失败场景、取消贯穿执行链、结构化错误与指标留痕。
   *证据*：恢复锁 CAS + TTL + 心跳；`cancel` 从"多跑 3 次调用"到"cancelled + ≤1 在途"。
3. **质量工程与数据化决策**：金标注 → 基线 → A/B → 预注册判据 → 决策记录 → 快照复现的完整闭环；允许写"结论未复现""这是显式偏离"。
   *证据*：12/12 文档一致性、38 条问题账本、翻默认记录含风险与回滚。

> 讲述边界：Agent 层是"已实现但未接线"（工具定义从未发给模型，每阶段实际一次 LLM 调用）；样本仅 3 本且全部 train。这两点要主动说，别让听众从代码里发现。
