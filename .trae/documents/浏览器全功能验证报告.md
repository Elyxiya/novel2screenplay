## 四、验证中发现并修复的问题

1. **结果页空场景崩溃** —— `result/[id]/page.tsx` 未生成场景时访问崩溃（读取 undefined.sceneNumber）。已加空态 UI 与 null 校验。
2. **selectedChapters 为空导致 LLM 幻觉** —— `PipelineEngine.ts` 收到 `[]` 时未回退全章节，导致抽取无关角色/地点。已改为空数组视为"未选择"，回退全部章节。
3. **存储引擎未初始化 500** —— 注册/上传 API 报 `No storage engine registered`。已在 `getEngine()` 入口做惰性初始化。
